# Architecture & Technical Decisions Record (ADR)

*Format: [Date] [ID] Decision | Why | Alternatives Considered*

---

| ID | Date | Decision | Why | Alternatives Considered |
|---|---|---|---|---|
| ADR-001 | 2026-11-15 | Flutter + Riverpod for cross-platform client | Strict budget (≤40MB APK), high-performance 60fps canvas tracing, reliable RTL text rendering, offline SQLite integration. | React Native (larger bridge overhead, weaker RTL canvas), Native Android Kotlin (no shared iOS code). |
| ADR-002 | 2026-11-15 | Pre-recorded native audio as primary playback; TTS as fallback only | Low-end Android devices in Pakistan lack high-quality offline Sindhi/Urdu neural TTS engines; human voice preserves exact dialect warmth. | Pure device TTS (fails in Sindhi, robotic Urdu), Cloud TTS (violates 100% offline requirement). |
| ADR-003 | 2026-11-15 | Noto Naskh Arabic as primary font; Noto Nastaliq Urdu as optional toggle | Noto Naskh Arabic has smaller footprint, reliable low-RAM rendering, no vertical glyph clipping, and native Sindhi character support. | Pure Nastaliq default (clips lines, high memory, poor Sindhi support), System default font (broken ligatures). |
| ADR-004 | 2026-11-15 | FastAPI + SQLAlchemy 2.0 + PostgreSQL 16 (PostGIS + pgvector) for Backend | Python ecosystem provides unified async APIs, pgvector for hybrid retrieval, PostGIS for accurate rural offline spatial boundaries. | Node.js/Express (fragmented GIS/AI ecosystem), Go (higher overhead for AI/retrieval integration). |
| ADR-005 | 2026-11-15 | Deterministic Rule Engine for pre/post LLM safety interception | Health, livestock emergencies, and chemical dosage inquiries must be blocked deterministically without relying on probabilistic LLM reasoning. | Relying purely on LLM system prompt guardrails (vulnerable to prompt injection and hallucinations). |
| ADR-006 | 2026-11-15 | SQLite via Drift with Max-Wins resolution for mastery & LWW for profiles | Guarantees non-destructive progress synchronization when devices spend weeks in rural airplane mode. | Simple timestamp overwrite (causes lost progress if clock is skewed), manual conflict UI (confuses non-literate users). |
| ADR-007 | 2026-11-15 | Picture-based 4-symbol PIN for shared family accounts | Enables out-of-school children and non-reading adults to maintain personal progress on a single household phone without text passwords. | Numeric 6-digit PIN (requires digit literacy), Biometrics (unavailable on cheap sub-$60 phones). |
| ADR-008 | 2026-11-15 | JSON Schema v7 validation for curriculum and knowledge assets | Enforces strict compile-time and CI content integrity before any content pack can be compiled or shipped. | Ad-hoc markdown parsing (fragile, lacks strict type checks), relational database seed scripts (hard to version control). |
| ADR-009 | 2026-11-16 | Revert MinIO container image to official minio/minio | Revert temporary unofficial image (elestio/minio) back to the official image specification per project policy. | elestio/minio, bitnami/minio, quay.io/minio/minio. |
| ADR-010 | 2026-11-16 | Pluggable StorageBackend with LocalDiskStorage for dev; defer S3/MinIO to Milestone 4 | MinIO public prebuilt images are restricted upstream; dev environment needs simple, reliable file storage for audio, images, and content packs without external daemon complexity. Pluggable StorageBackend interface allows LocalDiskStorage on Docker volume for Milestone 0-3 with S3 adapter stubbed for Milestone 4. | Unofficial MinIO images, mock S3 container. |
| ADR-011 | 2026-11-16 | Pivot to standalone Flutter Web clickable prototype; park Docker, backend, DB, Gradle, and APK work | Host disk exhaustion on C: (0.00 GB free) and need for an immediate supervisor demo require a zero-daemon, browser-runnable clickable prototype. Backend, Docker, database, and Gradle infrastructure parked (retained in repository, un-deleted). Client uses single Flutter codebase running on Web with SharedPreferences/localStorage, honest DEMO labels for simulated items, and 100% genuine Noto RTL typography. Code remains buildable for Android later. | Attempting Docker/Gradle workarounds under 0-byte host disk; deleting backend infrastructure. |
